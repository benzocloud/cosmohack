# BenzoLens — «Линза над полем»

BenzoLens сохраняет силуэт облачной B от BenzoCloud. Круглый просвет обозначает линзу, нижний повторяет крупную границу участка на карте. [Обзор и макет шапки](brand-overview.png).

## Какой файл выбрать

| Задача | Файл |
|---|---|
| Шапка сайта на светлом фоне | [Горизонтальный SVG](svg/benzolens-horizontal-primary.svg) |
| Шапка на тёмном фоне | [Горизонтальный SVG для тёмного фона](svg/benzolens-horizontal-dark.svg) |
| Компактная вертикальная композиция | [Вертикальный SVG](svg/benzolens-stacked-primary.svg) |
| Отдельный знак | [Знак SVG](svg/benzolens-symbol-primary.svg) |
| Фавикон от 16 px | [Адаптивный SVG](web/favicon.svg) и [ICO](web/favicon.ico) |
| Аватар или иконка приложения | [SVG на тёмной плашке](web/benzolens-app-icon.svg) и [PNG 512](web/icon-512.png) |

В `svg/` есть горизонтальная и вертикальная композиции, знак и надпись отдельно. У каждой композиции пять версий: основная, для тёмного фона, зелёная монохромная, чёрная и белая. В `png/` те же версии на прозрачном фоне.

## Правила

- На светлом фоне используйте Emerald `#00875A` для знака и Forest `#092D23` для названия. На Forest используйте Mint `#66E8AE` и белый `#FFFFFF`.
- Оставляйте с каждой стороны видимого знака или композиции свободное поле хотя бы в диаметр круглого просвета.
- Для обычного знака используйте SVG с высотой холста от 32 px. В 16–24 px используйте favicon или `benzolens-symbol-small-*.svg`. Для горизонтальной композиции рекомендуем 160 px. В компактной шапке панели светлая версия проверена при ширине 107 px. Для вертикальной композиции рекомендуем ширину от 120 px.
- Сохраняйте пропорции и прозрачные просветы. На пёстрых изображениях используйте однотонную подложку.
- Надпись набрана Manrope и переведена в кривые. Установка шрифта для логотипа не нужна. Шрифт для интерфейса и лицензия SIL OFL лежат в `font/`.

## Подключение в веб-приложении

Скопируйте содержимое `web/` в публичный корень и вставьте `web/head-snippet.html` в `<head>`. Если файлы лежат в подпапке, укажите её в ссылках из этого фрагмента. Пути в манифесте заданы относительно самого манифеста.

Для шапки приложения скопируйте нужный SVG в публичные ресурсы и задайте `alt="BenzoLens"`. Макет на обзорном листе показывает пример размещения на основе карты продукта.
